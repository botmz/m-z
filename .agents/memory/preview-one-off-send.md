---
name: Preview one-off sends
description: Keep manual preview sends separate from persistent automatic routing.
---

Sending from the preview page is a one-time action to the selected destination. It must not create or modify a persistent source-to-destination routing rule.

**Why:** The owner explicitly chose sending the current preview once rather than saving an automatic forwarding rule.

**How to apply:** Keep manual-send confirmation explicit, preserve the selected source/destination composition, and leave routing changes to the routing page.
